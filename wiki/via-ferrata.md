# Via Ferrata

**Summary**: Via ferrata activities planned for the trip — primarily the Brigata Tridentina on Sept 12, with an optional harder route on Piz Boe on Sept 11.

**Sources**: 202609_dolomites.md

**Last updated**: 2026-05-02

---

## Via Ferrata Brigata Tridentina al Pisciadu (Sept 12)

- **When**: Sept 12 (Sat)
- **AllTrails**: https://www.alltrails.com/trail/italy/south-tyrol/via-ferrata-brigata-tridentina-al-pisciadu
- **Guide**: https://inafarawayland.com/via-ferrata-brigata-tridentina/

### Highlights
- Famous for its **suspension bridge**
- Rifugio at the summit for a meal break
- Good summit views

### Planning note
The source notes this should be done before [[sassolungo]] (Sassolungo is Sept 10) because the Brigata Tridentina is geographically closer to the [[seceda]] area (source: 202609_dolomites.md). This ordering is already reflected in the [[itinerary]].

## Ferrata Piazzetta — Piz Boe (Sept 11, optional)

- **Difficulty**: Difficult
- **AllTrails**: https://www.alltrails.com/trail/italy/veneto/ferrata-piazzetta-piz-boe
- Optional harder variant for the [[piz-boe]] summit day
- Only attempt if group has appropriate via ferrata experience and gear

## Gear Requirements

Via ferrata requires specific safety gear beyond normal hiking equipment. Needed (see [[gear-and-packing]]):
- Via ferrata set (harness + lanyard — not listed in shopping list but implied)
- Helmet
- Gloves (recommended)

The shopping list in the source mentions crampons, hiking poles, and knee guard but does not explicitly list a via ferrata harness — needs verification before purchase.
